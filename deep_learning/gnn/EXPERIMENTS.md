# Experiment log

Query-conditioned playlist generation. Real data: 11,339 songs (Zenodo
#nowplaying playlists x HF audio features), test = held-out playlists,
random baseline hit@10 = 0.09%.

| # | Experiment | Data | hit@10 | Notes |
|---|------------|------|--------|-------|
| 0 | Learned token vocab (195 tokens), graph from all pairs | 12,820 pairs | 42.6% | Inflated: test co-listen edges leaked into the graph; easy test subset (vocab-named playlists only) |
| 1 | Frozen ModernBERT queries (gte-modernbert-base), train-only graph | 26,150 pairs | 33.5% | Open vocabulary: zero-shot wins ("melancholic rainy sunday" works); lexical anchors lost ("christmas" smoothed away) |
| 2 | Hybrid: dense + learned exact-match lexical tokens (180 words) | 26,150 pairs | 35.6% | "christmas" anchor recovered (all-Christmas playlist). Unmet-intent rate grows 1.4%→8.6% over training — attention concentrates on dominant facets, motivating exp 3 |
| 3 | + attention-coverage loss (w=1.0) and MMR decoding | 26,150 pairs | 35.7% | Unmet-intent rate 8.6% → 0.0% at zero accuracy cost. "heavy metal love songs" now surfaces GnR/Aerosmith ballads. MMR needs top-k-std scaling (raw logit scale destroys coherence); with it, "Love Hurts" appears while staying in-genre |
| 4 | Intent-dependent arcs, synthetic true-order data, unseen intent combos | 3,000 pairs | 53.1% / 52.9% | Plain GRU already learns intent→arc mapping and generalizes it: energy-trajectory corr +0.749 on fully held-out combos; phase-conditioned decoder +0.797 (modest gain). Unseen "punk night" generates a declining energy walk |
| 5 | Exp-3 recipe at hidden 128, 15 epochs, MPS | 26,150 pairs | 39.7% | Plateaus ~39.5% from epoch 9; unmet intents 0.0% throughout. MPS 100ms/step vs 126ms CPU at this size. Best qualitative results: vietnam query finds Dylan "Blowin' in the Wind" + CCR (real 70s protest material); punk-christmas finds Jimmy Eat World "Christmas Card" |
| 6 | Union graph: adjacency (bias 1.0) + window-4 co-membership edges (log-count weights), 306k edges | 26,150 pairs | 38.8% ✗ | NEGATIVE. Underperforms adjacency-only (39.5% @ same epochs) despite 3x edges. Weighted co-bias gives partial credit everywhere, blurring the sharp adjacency signal the next-song metric rewards. Failure analysis motivating it (73% w/ edge vs 5% w/o) points to content generalization, not softer edges |
| 7 | Content node features: ModernBERT song profiles (title+artist+album+genre+binned quals) ⊕ raw scalars incl. key/mode/duration ⊕ learned artist-ID emb | 26,150 pairs | **42.7%** (ndcg@10 0.227) | Best yet, leak-free. Bucket shifts vs exp 5: no-edge 5.2→8.9%, rare songs 9.7→11.8% (median rank 927→646), same-artist 86.9→89.7%, late positions +5. Epoch 3 already matched exp 5's final |
| 8 | + logit-adjusted softmax τ=0.3 (τ=1.0 over-corrected, killed at epoch 2) | 26,150 pairs | 41.7% (ndcg@10 0.219) | Textbook head/tail trade: rare songs 11.8→14.7% (median rank 646→398), pop 5-20 22.7→26.0%, pop 20-100 34.2→37.2%; head 46.6→44.6%. Net −0.7 overall BUT fixes the greedy popularity trap: deterministic "chill christmas morning" now returns actual chill Christmas songs instead of generic pop ballads |
| 9 | Expanded anchors (755: min-freq-10 words + 114 genre phrases, ModernBERT-init via shared projection) + learned coverage steering | 26,150 pairs | 42.8% (ndcg@10 0.226) | "synth pop"→genre:synth-pop anchors as one unit; "morning"/"synth" now anchor. Greedy "chill christmas morning synth pop" fixed WITHOUT logit adjustment (steering+anchors route). But: greedy decoding still artist-locks (Vince Guaraldi x7, Nirvana x10) on hard/impossible-intersection queries — motivates decode-time --max-artist cap (2, default on in ./play), which fixes it directly: e.g. "chill christmas death metal" now spans Pearl Jam/Nirvana/RHCP/Weezer/Foo Fighters/CCR instead of one artist |
| 10 | + random-context conditioning (--shuffle 0.5: half of training playlists get order permuted per sample) | 26,150 pairs | 43.0% (ndcg@10 0.238) | RecSys'18 finding applied: random subsets condition better than sequential prefixes, which also regularizes the adjacency-edge shortcut since our playlist order is alphabetical noise anyway. 14 epochs, still rising at 13 (peak 43.05%) |
| 11 | + deep residual GNN (--layers 4, direction-aware SAGE + LayerNorm) | 26,150 pairs | 44.2% (ndcg@10 0.247) | Contradicts LightGCN/UltraGCN's general depth skepticism — plausibly because our node features (ModernBERT profiles) benefit from extra nonlinear mixing that pure CF embeddings don't need. Consistently ~2pt ahead of exp 10 at every matched epoch |
| 12 | + direct genre-match bias (learned additive logit bonus for songs matching an anchored genre, same pattern as edge_bias) | 26,150 pairs | 44.2% (ndcg@10 0.246) | Aggregate metric unchanged (as expected — genre-matching songs are plausible anyway). Fixes user-reported rock-vs-pop query collapse (8/10 identical → 3/10 overlap), but only at inference-time strength 2.5x on top of the trained 0.48 bias. SIMPLIFIED post-hoc: since hit@10 was flat either way and the effect was entirely the manual multiplier, the learned scalar was removed — genre bias is now a pure decode-time feature (`--genre-strength`, no training-time parameter/cost). Recalibrated sweet spot under the parameter-free formula: 1.2. **Caveat found in exp 13's qualitative check: the sweet-spot value is checkpoint-specific** (it's added directly to that model's raw logit scale, which differs per training run) — 1.2 lost christmas on the exp-13 GAT model, 0.6 restored it. Not a universal constant; needs a quick per-checkpoint sweep |
| 13 | GATv2 song encoder (learned per-edge attention) replacing SAGE, same recipe as exp 11 | 26,150 pairs | **44.4%** (ndcg@10 0.248) | Best hit@10. Small but real gain over deep SAGE (exp 11). One transient dip at epoch 9 (loss 5.49, hit 42.3%) recovered by epoch 10 — plausibly attention-weight instability, not a structural issue. Confirms attention over the graph encoder is complementary to cross-attention in the decoder (different mechanisms, both worth having) |
| 14 | + position-discounted listwise set loss (--listwise 0.5, blended with CE), same recipe as exp 13 | 26,150 pairs | 42.7% ✗ (**ndcg@10 0.254**, best) | Clean trade-off, not a wash: −1.8 hit@10 for +0.006 ndcg@10 vs exp 13. Matches the gSASRec/sampled-softmax literature caution that approx-NDCG surrogates tend to lose to well-corrected pointwise CE specifically on top-K metrics — hit@10 IS a top-K metric, ndcg@10 (over the whole remaining set, softer) is where listwise's design intent shows. Not adopted as default; exp 13 remains best hit@10 |
| 15 | PinSage-style 2-hop-weighted decode bias (--ppr: direct edges full weight + 2-hop partial credit) replacing 1-hop-only adjacency, same recipe as exp 13 | 26,150 pairs | 44.0% ✗ (ndcg@10 0.246) | NEGATIVE, same pattern as exp 6: broadening/softening the graph signal dilutes the sharp adjacency signal the next-song metric rewards, even with a much cheaper/more principled construction (2-hop path-count, not raw co-membership) than exp 6's attempt. Two independent failures now point the same way — decode-time bias wants to stay sharp, not broad |
| 16 | Auxiliary cluster-ID loss (2-level residual k-means on exp-13 embeddings, k1=128/k2=32, aux weight 0.3), same recipe as exp 13 | 26,150 pairs | 43.9% ~ (ndcg@10 0.248) | NEUTRAL. Full bucket comparison vs exp 13: rare-song (pop 0-5) 16.1%→17.1% (+1.0, likely noise at n=380), no-edge 12.6%→11.7% (-0.9), head/other buckets flat. Cold-start diagnostic (exp-16 infra) already showed our encoder differentiates songs by content — an explicit cluster-prediction signal is largely REDUNDANT with what the main loss can already extract from the same embeddings, not new information. Explains why this didn't move the targeted bucket |
| 17 | Same recipe as exp 13, 30 epochs + cosine LR decay (1e-3→2e-5) instead of 14 epochs flat | 26,150 pairs | **45.3% peak / 45.2% final** (ndcg@10 0.258) | **STEP JUMP.** +0.86 over exp 13, the biggest single-experiment gain since exp 7. Confirms the diagnosis that every prior 14-epoch run was still improving at its last epoch — undertrained capacity, not architecture, was the remaining lever. Genuinely converged: plateaus tightly (45.2-45.3%) over the final 5 epochs as LR→0. One large transient dip at epoch 11 (39.1%, recovered by epoch 12) mid-decay, cause unclear. Caveat: saved checkpoint is the FINAL-epoch weights (45.20%), not the observed peak (45.30% at epoch 28) — no best-checkpoint saving implemented yet. Qualitative check: "synth-pop" queries now execute genre coherently (Erasure/Pet Shop Boys/New Order/Duran Duran) but the recurring dominant-facet-capture problem persists on a sharper model — "christmas" dropped entirely from a synth-pop+christmas query, "heavy metal love songs" still pure metal. hit@10 and the 0.0% unmet-intent-rate measure attention coverage, not multi-facet OUTPUT coverage — still an open problem, orthogonal to this win |
| 18 | Retest exp 15 (PPR/2-hop bias) under the exp-17 regime (30 epochs + decay) | 26,150 pairs | 45.1% peak / 44.9% final ✗ (ndcg@10 0.257) | Still negative, and now a CONTROLLED comparison (both exp 17 and 18 run 30 epochs + identical decay): −0.23 peak / −0.30 final vs exp 17. Confirms exp 15's verdict wasn't an undertraining artifact — PPR/2-hop bias is a genuine, if small, loss under proper convergence too. First use of the new best-checkpoint saving (model_ppr_long_best.pt, peak epoch 25) |
| 19 | Retest exp 16 (auxiliary cluster loss) under the exp-17 regime (30 epochs + decay) | 26,150 pairs | 44.9% peak / 44.7% final ✗ (ndcg@10 0.255) | Same verdict as exp 18: −0.37 peak / −0.54 final vs exp 17, controlled. Both retested "maybe-undertrained" negative results now settled as genuine, not artifacts of the old 14-epoch regime — closes out that question. Two large transient dips this run (epoch 7: 40.9%, epoch 15: 40.8%), both recovered within 1-2 epochs, more frequent than exp 17/18's single dip each — mildly suggests the aux loss adds some optimization noise, though not enough to change the verdict |
| 20 | Retest exp 8 (logit-adjusted softmax, τ=0.3) combined with exp 17's full winning recipe | 26,150 pairs | 44.7% peak / 44.5% final (aggregate −0.63 vs exp 17) | **REAL tail win, not a wash** — unlike exps 18/19's retests. Full bucket comparison vs exp 17: rare-song (pop 0-5) 19.2%→23.7% (+4.5, n=380), pop 5-20 25.0%→28.1% (+3.1, n=1317), pop 20-100 35.5%→39.2% (+3.7, n=5223) — consistent direction and size across all three tail buckets, not noise. Cost is concentrated on the head (49.7%→47.7%, −2.0) and aggregate (−0.5 to −0.7). A genuine deployment tradeoff: exp 17 (model_long.pt) wins on aggregate hit@10; exp 20 (model_logitadj_long_best.pt) wins on tail fairness/coverage. Bigger effect size than exp 8 saw on the older, weaker recipe — the stronger base model gives logit adjustment more room to work with |
